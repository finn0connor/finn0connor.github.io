IE-GB Interconnector Flow Prediction Model (XGBoost)

Developed a machine learning forecasting model using XGBoost to predict net IE–GB interconnector power flows at 30-minute resolution. The project focuses on feature engineering, hyperparameter optimisation, and model evaluation, with ongoing work to improve performance during periods of high market volatility and rapid flow reversals.

  • Engineered a feature set incorporating EPEX GB and SEMOpx day-ahead electricity prices, wind generation forecasts, electricity demand forecasts, cross-market price spread metrics, and lagged interconnector flow data.
  • Optimised model hyperparameters using Optuna with cross-validation to improve predictive performance and generalisation.
  • Evaluated model performance using standard regression metrics, achieving an R² of 0.4822, MAE of 257.74 MW, and RMSE of 343.26 MW.
  • Currently investigating additional features and modelling approaches to better capture abrupt market-driven flow changes and improve forecast accuracy during extreme operating conditions.
